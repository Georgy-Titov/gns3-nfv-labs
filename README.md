# Виртуализация сетевых функций 2026-2027

## Описание

Этот репозиторий посвящён учебной дисциплине «Виртуализация сетевых функций». Курс охватывает архитектуру программно-определяемых сетей (SDN) и концепцию Open Networking: дезагрегированное сетевое оборудование, уровни абстракции SAI и DPDK, сетевые операционные системы SONiC и OpenSwitch, а также оркестрацию сетевых сервисов.

Практическая часть посвящена виртуализации сетевых функций (NFV), контейнеризации с Docker и Kubernetes и технологиям Overlay-сетей. Лабораторные работы выполняются в GNS3, Docker, Containerlab и включают развертывание сетевых стендов на базе SONiC, настройку VXLAN и управление трафиком с помощью SDN-контроллеров и протокола OpenFlow. Курс формирует практические навыки проектирования и эксплуатации дезагрегированных сетей нового поколения.
